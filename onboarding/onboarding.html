2. Features Overview

Auto-Sync Active
  • ⚙️ Manual Task States (Gear Icon in Header)
    • Click ⚙️ on any Course card or Upcoming deadlines to toggle task controls.
    • States: ✅ Done ⭐ To-Do 🔎 Highlight ❌ Cancel ⚙️ Default
  • ⚡ Automatic Completion Detection
    • Course Summary: Auto-marks ✅ Done when max points (or min required score) is reached.
    • Red ✕ Removal: Auto-marks ✅ Done when a task's red ✕ (Not accepted yet) disappears.
  • 🎉 Party Mode Celebration
    • Confetti & neon celebration when a task auto-completes in Course Summary (configurable in popup).
  • 🆕 NEW Task Badges & Notifications
    • Highlights newly published assignments/exams with a NEW badge & toast on visit.
  • 🎨 Classic BRUTE UI & Layout Options (Toolbar Popup)
    • Toggle Classic BRUTE UI (Old Style).
    • Move Course summary table to bottom of course pages.
    • Auto-hide navbar plagiat banner until a new incident appears.
  • ☁️ Automatic Browser Sync & Local Auto-Heal
    • Tasks and settings sync automatically via your browser account (with local shadow backup so pre-sync edits on a new device auto-merge without data loss).
